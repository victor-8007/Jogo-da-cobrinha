# Jogo-da-cobrinha

Jogo da Cobrinha

Jogo simples feito com HTML, CSS e JavaScript com ajuda de IA.

Como jogar
Abra o arquivo index.html no navegador.
Use as setas do teclado para mover o quadrado azul.
Toque no quadrado vermelho para crescer e ganhar 1 ponto.
Se o quadrado azul bater no próprio rabo, aparece GAMEOVER com a sua pontuação.
